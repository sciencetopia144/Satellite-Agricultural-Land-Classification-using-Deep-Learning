Project Overview:-
This project aims to automate the classification of agricultural land types using satellite imagery. By utilizing Deep Learning (Convolutional Neural Networks), the system can distinguish between various land covers such as crops, forests, residential areas, and water bodies. This technology is essential for precision agriculture, urban planning, and environmental monitoring.


Key Features:-

1.Deep Learning Model: Implements a CNN-based architecture (e.g., ResNet, VGG, or Custom CNN) for high-accuracy feature extraction.

2.Remote Sensing Integration: Handles multispectral or RGB satellite data.

3.Performance Evaluation: Includes scripts for calculating Accuracy, Precision, Recall, and generating Confusion Matrices.

4.Preprocessing Pipeline: Data augmentation, normalization, and resizing specifically for satellite image tiles.
